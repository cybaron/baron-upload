ばろん アップロード

「ばろん アップロード」は、YouTube チャンネル「ばろん」の運営者が、自分で撮影・編集した旅の動画を、自分のチャンネルにアップロードするための個人用のツールです。運営者の PC の上だけで動きます。ほかの人に向けたサービスではありません。

できること

  • 編集の終わった動画を、YouTube Data API を使って自分のチャンネルにアップロードする。
  • タイトル・説明文・タグ・サムネイルを設定し、予約公開の日時を入れる。
  • 自分のチャンネルの動画のタイトルと説明文を直す。

個人情報の扱い

Google アカウントのデータをどう扱うかは、プライバシーポリシーに書いています。

English

"Baron Upload" is a personal tool used only by the owner of the YouTube channel "ばろん" to upload the owner's own travel videos to the owner's own channel, set titles, descriptions, tags, thumbnails and scheduled publishing times, and edit the titles and descriptions of the owner's own videos. It runs only on the owner's PC and is not offered to anyone else. See the Privacy Policy.

このツールは YouTube API サービスを使用しています。
