プライバシーポリシー

最終更新：2026年11月7日

「ばろん アップロード」（以下「このツール」）は、YouTube チャンネル「ばろん」の運営者が、自分の動画を自分のチャンネルにアップロードするための個人用のツールです。このツールが Google アカウントのデータをどう扱うかを、次のとおり定めます。

1. 使う Google のデータ

このツールは、運営者自身の Google アカウントで、次の権限を求めます。

  • https://www.googleapis.com/auth/youtube.upload：動画とサムネイルをアップロードするため。
  • https://www.googleapis.com/auth/youtube：自分のチャンネルの動画の一覧と予約公開の日時を読み、動画のタイトルと説明文を直し、再生リストに動画を加えるため。

2. データの使い方

読み書きするのは、運営者自身のチャンネルの動画の情報（タイトル・説明文・タグ・公開設定・予約公開の日時・再生リスト）だけです。上に書いた目的のほかには使いません。広告や分析には使いません。

3. データの保存

ログインの情報（アクセストークンとリフレッシュトークン）と、アップロードの記録は、運営者の PC の中だけに保存します。このツールにはサーバーが無く、データをほかの場所に送ることはありません。

4. 第三者への提供

Google アカウントのデータを、第三者に渡したり、売ったりすることはありません。動画やその情報が送られる先は YouTube（Google）だけです。

5. 権限の取り消し

このツールに与えた権限は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。取り消すと、このツールは YouTube を操作できなくなります。PC の中に残ったログインの情報は、運営者が消します。

6. YouTube API サービス

このツールは YouTube API サービスを使用しています。YouTube の利用には YouTube 利用規約が、Google によるデータの扱いには Google プライバシーポリシーが適用されます。

7. お問い合わせ

このポリシーについてのお問い合わせは、このページの GitHub リポジトリの Issues へお願いします。

English summary

This tool is used only by the owner of the YouTube channel "ばろん" with the owner's own Google account. It requests the scopes youtube.upload and youtube solely to upload the owner's own videos and thumbnails, read the owner's channel's video list and scheduled times, edit titles and descriptions of the owner's videos, and add them to playlists. OAuth tokens and logs are stored only on the owner's PC; there is no server. Google user data is never shared with or sold to third parties and is not used for advertising or analytics. Access can be revoked at any time at Google Account permissions. This tool uses YouTube API Services: YouTube Terms of Service, Google Privacy Policy.
